# Anna Fiore

Development economist working on gender, care, and labor markets.

I currently work with the World Bank's Development Impact Group (DECDI), verifying the computational reproducibility of research in the Policy Research Working Paper Series. Before that, I coordinated a randomized evaluation of childcare provision for market women in Kampala, Uganda, and led national survey studies on women's economic inactivity and fertility aspirations at UNFPA Bosnia and Herzegovina.

I work mainly in **Stata**, with **R** and **Python**, and design surveys in **SurveyCTO** and **ODK**. I care about code that someone else can run: clear folder structures, a single master script, and a README that maps every table and figure to the code that produces it.
